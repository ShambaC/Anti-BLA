# Benchmarks

Method and caveats: [../docs/benchmark-methodology.md](../docs/benchmark-methodology.md).

```bash
npm run build
node dist/benchmarks/runner.js                         # automated Anti-BLA arm -> results/antibla-auto-latest.{json,md}
node dist/benchmarks/runner.js --materialize <dir>     # write scenario targets (outside the repo) for a paired agent run
node dist/benchmarks/validate-results.js results/paired-<date>.json   # validate + summarize a paired run
```

- `scenarios.json`: scenarios, questions, ground truth and expected/forbidden Anti-BLA rules.
- `results/antibla-auto-latest.*`: latest automated run (regenerated by CI).
- `results/paired-2026-11-10.*`: recorded REA-only vs REA+Anti-BLA run (n = 1, not blinded).

The runner spawns only `node dist/src/cli.js` with argument arrays; it never runs shell fragments or target code.

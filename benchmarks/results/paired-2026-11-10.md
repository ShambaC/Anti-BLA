# Paired benchmark paired-2026-11-10 (2026-11-10)

Model: Claude Sonnet 5.5 (Claude Code general-purpose subagent), same model and prompt template in both arms. Repetitions: 1. Blinded: false. Grader: implementing agent (Claude Opus 5.5) against benchmarks/scenarios.json ground truth; not independent.

- Arms ran sequentially on one shared REA 6.8.0 MCP server (no settings changed by either arm); targets materialized outside the repository.
- REA WABT and SQLite providers were unavailable on this host, so REA could not contribute to 4 of 7 scenarios in either arm; in the remaining 3 the arm-A agent found REA output too large for its display and fell back to manual parsing.
- Fixtures are small and hand-parsable, so both arms reached the same fact accuracy; this run cannot show an accuracy benefit.
- Observed differences: arm B made 2 REA calls vs 7, 12 vs 15 tool calls, ~1% more tokens and ~4% more wall time; arm A attempted to evaluate the SQLite trap column, arm B did not; arm B made one incorrect extra claim on a negative control.
- Neither arm executed the ASAR recovery workflow; that workflow was exercised separately (docs/compatibility.md).
